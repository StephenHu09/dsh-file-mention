方案细节

① 类型图标（4 类 emoji）

DSH 菜单 icon 字段为纯文本渲染，emoji 是文本且跨平台渲染稳定；按扩展名映射为 4 类：

代码含常见编程语言与脚本扩展名；文档为 .md/.txt/.rst；图片为常见位图/矢量格式；其余全部归「其他」。

② 变更标记（行尾字母）

菜单不渲染 hint 字段；description 是行尾元素（flex:1），在其尾部追加低饱和状态字母（M/A/D/R）：

M 修改 A 新增 / 未跟踪 D 已删除（暂存） R 重命名

真实实现：description 尾部追加 M（同色），onPick 插入前用正则剥离尾部字母，保证插入的仍是干净路径。

③ 不可行的项（组件限制）

调研 DSH 菜单组件源码后确认以下设计无法在真实菜单实现：

✗ SVG 线条图标 —— icon 为纯文本渲染
✗ 右侧状态徽标 —— hint 字段不渲染
✗ 浅蓝选中色 —— 高亮由组件 CSS 控制
✗ 路径截断 —— description 即插入值
说明：本页为真实渲染效果的模拟（菜单底色/字体/选中样式仍由 DSH 组件决定，此处仅示意数据呈现）。演示页 docs/ui-preview.html 中的 SVG 线条图标方案因组件限制无法落地，故转为文本符号方案。
