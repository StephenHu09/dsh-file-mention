## v0.1.16（2026-08-15 · 待发布）

合并 v0.1.15 全部内容（性能批次，v0.1.15 未单独发布）+ 段索引等价性修复：

- **目录引用**：目录由文件列表自动派生（deriveDirs，零额外扫描），@ 菜单可选中目录并插入 `@docs/ ` 供模型探索；📁 图标、名称带尾斜杠；**集中置前**（变更文件 → 目录 → 普通文件 → 隐藏路径）
- **目录逐级展开**（visibleDirs）：深度 = 查询词 `/` 数量 + 1（`@app/` 第二层）；**单段查询直达子目录**（basename 前缀突破深度，`@10_logcat_analyze` 直达）
- **变更置顶限数量**：dirty 携带 mtime（host node:fs stat），只置顶最近修改的 5 个（TOP_DIRTY，mtime 降序）；无 mtime 旧格式回退全量置顶
- **输入卡顿优化**：score 分层 + limit 即停 + rank 预计算 + deriveDirs/buildIndex 缓存 + **段索引**（路径拆段、首字符分桶、段→路径倒排、12 桶直接分流）——3 万文件 45-57ms → 4-15ms；真实项目（1541 文件）0.2-1.4ms
- **limit 30**：DSH 菜单无虚拟化全量渲染，行数即渲染成本，30 条足够浏览
- **段索引等价性修复**（等价性测试驱动）：单段查询改为遍历全部段名（只查 q[0] 首字符桶会漏检首字符不同的命中段，如 'main' 含 'a'）；buildIndex 路径内段去重（同路径同名段重复入倒排导致结果重复）；新增段索引 vs 全扫描等价性测试（确定性 + 随机 2000 路径）与 3 万文件性能边界测试（<150ms 防退化）
- **排序回归矩阵**：score/rank/mtime 叠加完整顺序快照测试，规则改动必须同步更新
- 测试 54 单测 + 20 集成
